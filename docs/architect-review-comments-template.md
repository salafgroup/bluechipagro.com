## Technical Severity Definitions

*   **Critical:** Potential structural code failure, zoning buffer violation, environmental stream buffer infringement, or immediate TCP statutory non-compliance. Re-drafting and engineering re-calculation is required.
*   **Major:** Spatial flow mismatch, incorrect door/window clearance sizing, stilt structural axis misalignment, or major dimension label errors. Re-drafting required.
*   **Minor:** Linework cosmetic overlap, minor layer naming mismatch, text annotation typo, or graphic scale bar visual tweaks. Quick CAD draft tweak required.
